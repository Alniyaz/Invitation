# Add your gallery photos

1. Copy your three couple photos into this folder.
2. Open `../../script.js` and find the `galleryPhotos` list at the top.
3. Replace each empty quote with the file path, for example:

```js
const galleryPhotos = [
  'assets/gallery/parthiban-manjula-01.jpg',
  'assets/gallery/parthiban-manjula-02.jpg',
  'assets/gallery/my love.png'
];
```

JPG, PNG, and WebP files all work. Each frame uses the center of the image, so portrait photos look best.
